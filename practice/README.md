# Independent practice write-ups

Simpan full write-up untuk challenge self-paced, crackme, wargame, dan authorized training lab di sini.

## Folder convention

Gunakan **satu folder per platform/source** dan **satu file Markdown per challenge**. Buat folder ketika ada write-up pertama yang memang boleh dipublikasikan; jangan membuat banyak folder kosong hanya untuk mengisi daftar platform.

```text
practice/
├── README.md
├── PLATFORM-INDEX.md
├── Crackmes.one/
│   ├── XorGate.md
│   └── muhemed-crackme.md
└── <platform-name>/
    └── <challenge-name>.md
```

Write-up harus mengikuti aturan sumber. Beberapa platform membatasi publikasi solusi atau materi challenge. Status izin diperiksa per challenge; jangan berasumsi semua konten dari satu platform memiliki aturan yang sama.

Current examples: [XorGate](Crackmes.one/XorGate.md) and [muhemed crackme](Crackmes.one/muhemed-crackme.md), both from Crackmes.one.

Full write-up latihan mandiri hanya disimpan di sini. `ctf-track-record` hanya untuk catatan event resmi. `reverse-engineering-lab` boleh menyimpan eksperimen/kode pendukung yang berdiri sendiri, tetapi bukan salinan full write-up.
